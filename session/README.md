# Taekwondo Club Attendance PWA — Session Roadmap Tracker

This directory maintains phase-by-phase records of the architecture, implementation steps, testing, and milestones achieved across the 21-phase roadmap.

## Project Summary
- **App Name**: Taekwondo Club Attendance & Fee Management PWA
- **Tech Stack**: Next.js 16 (App Router, TypeScript), Tailwind CSS, Supabase (Auth + PostgreSQL + RLS), PWA (Service Worker + Web App Manifest), Lucide Icons
- **Target Audience**: Club Admin (Teacher) & Students (Read-only personal portal)
- **Directory**: `taekwondo-club/`
